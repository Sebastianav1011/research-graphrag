# Pruebas preservadas

- `piloto_v2/`: evidencia del piloto aceptado y la publicación V2 vigente.
- `validacion_v3_3/`: respuestas V3 originales, consolidación recuperada, controles
  semánticos V3.3 y preparación de llamadas independientes. No es una publicación.

Los README de cada carpeta describen sus resultados y límites. Los intentos
fallidos y continuaciones necesarios para auditoría se conservan. Pruebas antiguas
con dependencias de fingerprints están indexadas en `../auditoria/README.md`;
no deben confundirse con resultados actuales.
